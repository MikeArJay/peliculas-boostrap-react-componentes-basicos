# Ejercicio componentes básicos react para diseño de interfaces

Con el fichero peliculas, crea un página con la imagen de una película ocupando 8 celdas de la primera fila y la información sobre título , director , actores y sinopsis en las 4 celdas restantes.

Distribuye las siguientes películas del fichero en elementos Cards que ocupen 3 celdas cada una, con la imagen en la parte superior. La Card debe contener la imagen,título , director y actores. Si se pulsa sobre el botón Más se verá la sinopsis. Si se pulsa sobre el botón seleccionar sitúa la película en la primera fila.
